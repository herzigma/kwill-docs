# Kwill Release Notes & Roadmap

## Release notes

### February 9, 2025

- Uploaded logos and favicons no longer randomly disappear
- Social metadata is now consistently showing

### February 6, 2025

- Create a new campaign by duplicating an existing one

### February 3, 2025

- Can now change campaign status: Pending ⇒ Live ⇒ Finished
- Filter campaigns list by status and organization
- Pending campaigns aren’t publicly visible (redirects you to a public Organization page)
- Finished campaigns have a message indicating such, no longer generate letters, and offers a link to the organization page

### February 1, 2025

- Optionally add multiple CC email addresses to letter campaigns

### January 26, 2025

Fixed the following bugs:

- Links in campaign instructions not clickable
- Users table not showing users
- Letter tester is not working
- Line breaks lost on email from iPhone
- Need to HTML encode mailto: links

### January 19, 2025

- Refactored prompt generation to increase flexibility.
- Created a “Letter Tester” page so you can more quickly test your prompts.
- Improved user roles and permissions to support multiple simultaneous organizations.
- Added metatags to public Campaign Letter pages to improve social sharing
- Fixed numerous bugs.
